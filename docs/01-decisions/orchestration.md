# Orchestration

**What it is:** the tool that runs the stages in order, keeps the queue of videos, and reports failures.

## Options

| Tool | Cost | Style | Notes |
|---|---|---|---|
| [n8n](https://n8n.io/) | Free to self-host (Sustainable Use License) | Visual workflows + code nodes | Forms, webhooks, a built-in Data Table for the queue, YouTube node, OAuth handling. Popular for this exact use |
| [Activepieces](https://www.activepieces.com/) | Free self-hosted (open source) | Visual | Similar idea to n8n, MIT-licensed core |
| Make / Zapier | Paid (free tiers small) | Visual, cloud | No server, but runs that render video use many operations |
| Your own script (Node.js, Python) + cron or a task scheduler | Free | Code | Full control; you build the queue, retries and error reporting yourself |
| Windmill, Temporal, Airflow | Free self-hosted | Code-first workflows | Powerful; more setup than a small channel needs |

## What any orchestrator must do

- **Queue with statuses**: for example `queued → rendering → rendered → uploading → uploaded`, or
  `failed` with the step and error message. One row per video.
- **One video at a time per stage**, in a defined order (oldest first; series parts in order).
- **Retries for flaky services** (image sites, TTS) with pauses between attempts. **No automatic retry
  for uploads**: a retried upload can post the same video twice.
- **A clear failure report**: which video, which step, what error.
- **Triggers you choose**: a button/form you press, or a schedule. Starting with buttons is safer.

## If you use n8n

- Build workflows **as code** (JSON generated by a script) and deploy them through n8n's API, then
  don't edit them in the UI. Workflows become reviewable, testable, and recreatable.
- n8n's public API needs an API key (Settings → n8n API). Webhooks need a moment after activation
  before they answer.
- Read [05-lessons-learned.md](../05-lessons-learned.md) for n8n specifics.

## Ask yourself

1. When a video fails at 3 a.m., how do I find out, and how do I retry just that step?
2. Do I want to click through a visual editor or write code?
3. Can I recreate the whole setup on a new computer from what's in my repo?
